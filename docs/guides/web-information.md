# 등록형 공개 웹 정보 수집과 제한형 검색

[문서 안내](../README.md) · [현재 계획](../PLAN.md)

## 사용 예시

추가 원문 도구 `read_public_web_page(url)`는 공개 HTTPS HTML/텍스트 한 페이지에서 최대3000자의 정적 텍스트를 읽습니다. 공통 DNS/IP 고정·리디렉션/압축 거부·크기/시간·중단/예산 제한을 재사용하며 로그인·쿠키·JS 실행·파일 저장을 하지 않습니다. 이 도구를 포함해 총31개입니다. MCP에서는 명시한 공개 주소를 입력할 수 있지만, 채팅은 현재 요청의 성공 검색 결과 주소와 정확히 일치할 때만 허용합니다. 이전 대화의 주소·모델이 만든 주소·다른 URL로의 변경을 허용하지 않습니다. 현재 ChatDecision 인자 제한 때문에 채팅 URL은800자 이내여야 합니다.

예: “Python 공식 사이트를 웹에서 검색한 뒤 검색 결과 페이지의 원문 일부를 읽어줘.” 검색1회→페이지1회로 기존 도구2회 한도를 사용합니다. 최종 답은 읽은 텍스트·출처·조회 시각으로 구성하며 검색 발췌와 구분합니다. 스크립트 의존 페이지의 대체 문구·메뉴가 포함되거나 앞부분만 읽힐 수 있습니다. CAPTCHA/차단 페이지·빈 본문·PDF 등 미지원 형식·리디렉션은 실패로 처리합니다. 페이지를 읽었다는 사실이 내용의 정확성·최신성 또는 전체 문서 검토를 증명하지 않습니다.

2026-10-20 추가: `search_public_web(query, limit=3)`는 고정 Bing RSS 검색에 공개 검색어를 전달하고 최대3개의 제목·발췌·HTTPS 결과 주소와 UTC 조회 시각을 반환합니다. 검색어는 2–200자이며 인증정보·제어문자·상한 초과를 거부합니다. 검색어가 외부 Bing으로 전달되므로 개인정보나 비밀을 넣지 않습니다. API 키·로그인·쿠키를 사용하지 않고 원문 페이지를 자동으로 열거나 보고서를 저장하지 않습니다. 기존29개에 추가되어 총30개 MCP 도구입니다. 실행 중 MCP 클라이언트는 재연결이 필요합니다.

요청은 기존 공개 IP 검사·검증 IP 고정·리디렉션/압축 거부·512KiB·작업자12초 상한을 재사용합니다. 공통 중단/시간창 도구 예산도 적용합니다. HTML 차단 페이지·빈 결과·주요 검색어와 겹치지 않는 발췌는 성공으로 취급하지 않습니다. 관련성 검사는 어휘 기반의 보수적 검사로 번역·유의어를 놓치거나 무관한 결과를 통과시킬 수 있습니다. Bing RSS의 가용성/결과 품질은 보장하지 않으며 검색 순서가 실시간 인기 순위를 뜻하지 않습니다. 결과 URL은 데이터로만 반환하고 자동 접속하지 않습니다.

채팅에서는 로컬 모델이 검색 도구와 검색어를 선택합니다. 비ASCII 검색어를 짧은 영어 검색어로 다듬는 로컬 추론은 추가 예약 예산을 소비하며 번역 정확성을 보장하지 않습니다. 검색 응답은 최종 모델이 생성한 추가 사실·링크 대신 실제 반환된 발췌로 구성합니다. 근거 ID/조회 시각은 서버가 부여합니다. 이는 Agent Reach 전체 검색 연결이 아니며 원문 내용·정확성·최신성까지 검증한 결과가 아닙니다.

다음 두 도구는 기존 등록형 수집 기능입니다. 등록된 출처 목록은 일반 웹 검색 결과와 구분됩니다.

- `list_web_sources()`: 등록한 출처·주소·종류를 확인합니다. 네트워크 요청을 보내지 않습니다.
- `collect_web_information(source_ids, max_items=5, save_report=True)`: 출처를 최대 3개 선택해 출처별 항목을 최대 5개 수집합니다. 중복 ID·잘못된 유형·한도 초과를 거부합니다.

예를 들어 “자비스로 Python 소식과 BBC 세계 뉴스, 서울 날씨를 하나씩 수집해서 저장해줘”는 `source_ids=["python-news", "bbc-world", "seoul-weather"], max_items=1`입니다. “허용된 웹 출처 보여줘”로 목록을 먼저 확인해도 됩니다.

현재 출처:

- `python-news`: Python 공식 블로그 RSS. 최근 5개 범위에서 제공 순서대로 읽습니다.
- `bbc-world`: BBC 세계 뉴스 RSS. 제목·게시일·배포자가 제공한 설명을 추출합니다.
- `python-docs`: Python 3.13 공식 변경 안내. 버전이 고정된 문서이며 최신 버전 검색은 아닙니다.
- `seoul-weather`: Open-Meteo의 서울 현재 기온·습도·기상 코드와 관측 시각입니다. **서울 좌표를 고정 사용하며 사용자 현재 위치가 아닙니다.** 출처를 결과에 표시합니다.

날씨 요청에는 고정 서울 좌표만 전달합니다. 시스템 위치·문서·계정·채팅 내용은 보내지 않습니다. BBC/Python에는 등록한 공개 주소에만 GET을 보냅니다. 별도 검색 제공자·유료 API 키·요약 모델 없이 동작합니다.

## 결과와 저장

결과에는 `generated_at`, 출처별 `fetched_at`(요청 시작 시각, UTC), 출처 URL, 게시일/관측 시각, 제목·짧은 발췌, 출처별 성공/오류가 있습니다. 시각은 ISO 8601이며 게시일은 출처가 제공한 문자열입니다. 전체 `status`는 `ok`, `partial`, `error`를 구분합니다. 일부 출처 실패를 전체 성공이나 빈 정상 결과로 숨기지 않습니다.

기본 저장 위치는 `JarvisWorkspace/reports/web/<고유 ID>.txt`이며 UTF-8 구조화 텍스트(JSON)입니다. 원본 HTML·전체 기사·실행 파일을 저장하지 않고 같은 이름의 파일을 덮어쓰지 않습니다. 기본 documents 검색 인덱스에는 자동 추가하지 않습니다. `save_report=False`면 저장하지 않습니다. 실패한 수집도 오류를 담은 보고서로 남길 수 있으며 디스크 저장 자체가 실패하면 도구 오류를 반환합니다. 디스크 오류 시 작성 중인 불완전 파일이 남을 가능성이 있습니다.

요약은 **배포자 설명 또는 첫 부분 발췌**입니다. 출처별 최대 5개, 항목당 최대 500자이며 제목은 300자까지입니다. 일반 웹 검색·기사 전문 읽기·AI 의미 요약·독립 사실 확인·자동 번역·브라우저 렌더링을 수행하지 않습니다. 뉴스의 최신성·발췌의 완전성은 출처에 달려 있습니다. 결과와 저장 파일은 모두 `untrusted_content=true`인 데이터이며 내용 속 명령은 실행하지 않습니다.

## 보안 경계

- 운영자 코드 영역 `config/web_sources.json`에서 고정 HTTPS 주소와 정확한 접속/기사 링크 호스트를 등록합니다. MCP 인자로 임의 URL·검색어·헤더·자격 증명·파일 경로를 받지 않습니다. 데이터 작업공간 안의 설정, 링크·정션·하드링크 설정 파일을 거부합니다. 새 출처의 등록은 신뢰된 코드 설정 변경에 해당합니다.
- HTTPS 443만 사용하며 인증정보·fragment·제어 문자·자격 증명처럼 보이는 query 인자를 거부합니다. 내부/로컬·링크 로컬·예약 IP와 IPv6 전환 주소를 거부합니다. DNS 응답의 모든 IP를 확인한 뒤 확인한 숫자 주소로 직접 연결하고 원래 호스트의 SNI·인증서 검증을 유지합니다. 재시도에서도 재조회한 미검증 주소로 연결하지 않습니다.
- 프록시 환경변수·브라우저 쿠키·로그인 세션·API 키를 사용하지 않습니다. 리디렉션은 따라가지 않고 HTTP 200 외 응답을 오류로 기록합니다. 자동 로그인·유료벽 회피·첨부파일 다운로드는 없습니다.
- 출처당 최대 2개 검증 주소에 연결을 시도합니다. 응답은 최대 512 KiB이며 압축 응답을 거부합니다. 별도 Python 작업자의 전체 실행을 부모가 출처당 12초 상한으로 관리하고 약 0.2초 간격으로 중단 파일을 확인해 작업자를 종료합니다. DNS·느린 헤더도 이 작업자 상한에 포함됩니다. 요청 1회가 동시에 여러 모델 호출을 만드는 구조는 아닙니다.
- XML은 DTD·ENTITY를 거부하고 RSS/Atom 루트·노드 10,000개·깊이 40을 확인합니다. 잘못된 링크·MIME·인코딩·데이터 형식을 거부합니다. Python RSS가 실제로 일반 바이너리 MIME을 반환하는 경우 XML 선언과 RSS/Atom 구조까지 검증한 뒤 허용하고 경고를 남깁니다. HTML은 스크립트·스타일·메뉴·폼 등을 제외한 텍스트만 추출하고 실행하지 않습니다.
- 공통 시간창 호출 예산([시스템 도구](system-tools.md))과 `.jarvis-stop`이 적용됩니다. 한 collect가 1회이며 내부 네트워크 시도도 별도 상한을 갖습니다. OS 전체 네트워크 격리나 전역 요청 빈도 제한은 아니며 기존 경로 검사 직후의 동시 파일 교체 위험도 남습니다. 인식 가능한 비밀값 가림은 최선 노력이며 모든 민감정보 탐지를 보장하지 않습니다.

## 검증과 남은 범위

웹 수집·플러그인·Phase 1 관련 **90개 통과 / 건너뜀 0개**입니다. 이전에 Windows 심볼릭 링크 생성 권한 때문에 건너뛴 검사를 실제 디렉터리 정션으로 개선했습니다. 보고서 루트의 외부 연결, reports/web 하위의 외부 연결, 작업공간 내부를 가리키는 연결 모두 생성 여부를 확인한 뒤 저장 거부와 대상 파일 미변경을 검증했습니다. 정션 생성 실패는 검사 실패로 처리하며 건너뛰지 않습니다. Windows의 심볼릭 링크 권한 자체를 변경하거나 그 링크 유형의 생성을 검증한 것은 아닙니다. 일반 경로·DNS/IP·TLS 고정·HTTP 경계·작업자 정리·출처별 오류·기존 계약과 실제 stdio 등록도 통과했습니다. 전체 프로젝트 테스트를 재실행한 결과는 아닙니다.

2026-10-18 실제 stdio MCP에서 출처 3종(Python RSS/BBC RSS/서울 날씨)을 각 1개씩 수집해 `status=ok`와 보고서 저장을 확인했습니다. Python 공식 HTML 문서 출처도 별도 실제 수집에 성공했습니다. 세부 이력은 [Phase 2 보고서](../reports/phase-02.md)를 따릅니다.

검색엔진 기반 탐색, 임의 사이트, 다른 도시·예보, 자동 예약, 기사 전문, 신경망 요약은 후속 확장입니다. 다음 큰 단계는 Phase 2.5의 역할별 협업·기억·재시도·이벤트 설계이며 이번에는 구현하지 않았습니다.
