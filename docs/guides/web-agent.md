# 웹 작업 에이전트 (M2)

어떤 두뇌(기본 로컬 qwen 포함)든 공개 웹 작업 하나를 끝까지 하도록 자비스가 도구를 쥐고 실행하는 고리입니다. 코드는 `jarvis/features/web_agent/service.py`입니다. 채팅·HUD 연결은 M4에서 합니다.

## 모델이 고르는 것
매 단계 모델은 JSON 스키마의 선택지 하나만 고릅니다. 브라우저 도구를 직접 받지 않습니다.
- `search(query)`: 브라우저로 Bing 결과 페이지를 열고 자비스가 결과를 번호로 정리합니다(Bing 추적 링크는 원래 주소로 풉니다).
- `open(number)`: 번호 붙은 검색 결과·요청에 적힌 주소·페이지 링크를 엽니다. HTTPS 읽기 일꾼을 먼저 쓰고, 본문이 짧거나 실패하면 브라우저로 엽니다.
- `press(number)`: 지금 브라우저에 열린 페이지의 버튼을 누릅니다. 로그인·가입·결제·주문·글쓰기·전송·삭제 같은 버튼은 아예 보여주지 않고, 누를 때 한 번 더 막습니다.
- `download(number)`: 사용자 요청에 내려받기 말이 있을 때만 나옵니다.
- `answer(answer, sources)`: 최종 답과 근거 페이지 번호. 자비스가 실제로 읽은 페이지 주소로 "출처:" 목록을 붙입니다.

번호는 이 작업에서 자비스가 건넨 것만 고를 수 있어서, 모델이 주소를 만들거나 바꿀 수 없습니다. 이미 한 행동은 다시 나오지 않습니다(같은 검색어도). 스키마에 없는 선택은 거부하고, 3번 틀리면 답만 고르게 합니다.

## 주소 관문
- 브라우저가 가기 전에: https, 443 포트, 계정·토큰 같은 매개변수 없음, DNS 주소가 모두 공인 주소(`validate_url`, `public_addresses`).
- 페이지가 열린 뒤: 최종 "Page URL"을 다시 검사하고, 공인이 아니면 `about:blank`로 떠나며 내용을 읽지 않습니다.
- 첫 겹으로 Playwright에 `--blocked-origins`(localhost, 127.0.0.1, ::1)를 줍니다. 공식 문서상 보안 경계가 아니라서 자비스 검사가 본 관문입니다.

## 한도 (기본값)
- 작업당 도구 30회, 10분, 검색 4번. 마지막 45초는 답 고르기에 남깁니다. 시간이 다 되면 실패로 끝냅니다.
- 결과 8개, 새 페이지 본문 3000자(앞 페이지는 300자로 줄임), 링크 20개, 버튼 8개.
- 프롬프트는 약 12000자 안으로 유지합니다(로컬 채팅 일꾼이 8192토큰 문맥).
- 빈 답은 한 번 다시 묻고, 또 비면 실패로 끝냅니다. 중지 표시(`.jarvis-stop`)는 매 단계 확인합니다.

## 내려받기
- 파일은 Playwright 출력 폴더(격리 폴더)에만 떨어집니다. 열거나 실행하지 않습니다.
- 허용 확장자: pdf, csv, txt, json, png, jpg, gif, xlsx, docx, pptx, hwp, hwpx, xls. 확장자와 첫 바이트가 맞아야 하고 20MB 이하여야 합니다.
- Microsoft Defender로 검사합니다. 깨끗하면 `downloads` 폴더로 옮기고, 위협이면 지우고, 검사를 못 하면 격리 폴더에 둔 채 저장 완료로 알리지 않습니다.

## 벤치마크
`scripts/web_eval/run.py --driver jarvis`가 이 고리를 qwen3.5:9b로 돌립니다([웹 작업 벤치마크](web-eval.md)).
